# Кейс-задача № 1 — Сумма отрицательных элементов между max и min

##  Задание

Дан одномерный массив `A` размерности `N`.
Найти сумму отрицательных элементов, расположенных **между** максимальным и минимальным элементами.

## Что делает программа

1. Запрашивает у пользователя размер массива `N` (1..100).
2. Запрашивает `N` целых чисел.
3. Находит индексы максимального и минимального элементов.
4. Определяет, какой из них левее, а какой правее.
5. Суммирует все отрицательные элементы между ними (сами max и min не включаются).
6. Выводит результат (или сообщение, что отрицательных нет).


##  Пример работы

```
Введите размер массива N: 6
Введите 6 элементов массива:
A[0] = 4
A[1] = -2
A[2] = -3
A[3] = 1
A[4] = -5
A[5] = -6

Максимальный элемент: A[0] = 4
Минимальный элемент:  A[5] = -6

Элементы между max и min (индексы 2..5):
Найдено отрицательных: 3
Сумма отрицательных элементов = -10
```

Проверка вручную:
- массив: `[4, -2, -3, 1, -5, -6]`
- max = 4 (индекс 0), min = -6 (индекс 5)
- между ними: `-2, -3, 1, -5`
- отрицательные: `-2 + (-3) + (-5) = -10` ✅

##  Ограничения

- Массив ограничен 100 элементами (для учебной задачи достаточно).
- Если max и min стоят рядом — сумма равна 0 (между ними ничего нет).
- Если все элементы одинаковые — iMax = iMin = 0, сумма = 0.
- Ввод только целых чисел; при вводе букв программа зациклится (для новичка — допустимо, усложнение см. в «Что можно улучшить»).
